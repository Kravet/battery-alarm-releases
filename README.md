# Battery Alarm Releases

Battery Alarm is an Android app that monitors battery level and can sound an alarm when the battery is low.

## Downloads

Browse [all Battery Alarm releases](https://github.com/Kravet/battery-alarm-releases/releases). No APK has been published here yet. When a stable release is available, it will appear on the [latest stable release page](https://github.com/Kravet/battery-alarm-releases/releases/latest) with an APK named `BatteryAlarm.apk`, available through the [direct stable download link](https://github.com/Kravet/battery-alarm-releases/releases/latest/download/BatteryAlarm.apk). Beta downloads will be listed on their individual prerelease pages.

## Install on Android

1. Download the APK asset from a release page to your Android device.
2. Open the downloaded APK. If Android asks, allow your browser or file manager to install apps from that source, then return and open the APK again.
3. Review the installer and tap **Install**. Open Battery Alarm when installation finishes.

Android may show a warning when installing an app outside Google Play. Install only APKs from this repository's release pages. Menu names can vary by Android version and device maker.

## Beta versions

Beta versions are early builds for testing. Developer betas may have incomplete features or known issues; public betas have had additional testing but may still change. Beta releases are marked **Pre-release** on GitHub. For a regular release, use the latest stable release instead.

## Updates

Automatic update checking is not available yet. Check this page for release announcements and download updates manually. The app may add an update checker in a future version; this page will be updated when it is available.
