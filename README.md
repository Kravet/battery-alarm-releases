# Battery Alarm Releases

Android app that alarms when battery is low.

## Download

- [Latest stable](https://github.com/Kravet/battery-alarm-releases/releases/latest)
- [All releases](https://github.com/Kravet/battery-alarm-releases/releases)

## Install

1. Download the APK from the release page.
2. Open it and allow install from that source if Android asks.

## Updates

The app can check for updates itself. You can also download newer APKs here.
